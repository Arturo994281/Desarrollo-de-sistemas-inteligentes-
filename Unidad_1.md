**Act.1.2 Casos de uso de Zabbix.**

**Monitoreo de servidores:** Zabbix puede vigilar servidores Windows o Linux para conocer el uso de CPU, memoria RAM, almacenamiento y procesos.

**Monitoreo de redes:** Se puede utilizar para supervisar routers, switches y puntos de acceso, detectando pérdida de conexión, tráfico excesivo o interfaces caídas.

**Monitoreo de bases de datos:** Zabbix puede supervisar bases de datos como MySQL, PostgreSQL u Oracle, revisando conexiones, rendimiento y espacio disponible.

**Monitoreo de aplicaciones y servicios web:** Puede comprobar que una página web o aplicación esté disponible y respondiendo correctamente, generando alertas cuando deja de funcionar.

**Monitoreo de infraestructura virtual:** Zabbix puede supervisar máquinas virtuales y plataformas de virtualización, revisando CPU, memoria, almacenamiento y estado de las máquinas virtuales.
